# BIOL 363: dataset re-check and geometry analysis

Work on the nuclear receptor coactivator / corepressor project, by month. Each folder keeps the layout of the project folder `BIOL 363/`, so the scripts run from there.

| Folder | What it holds |
|---|---|
| `october_2026/dataset_recheck/` | Re-check of every exclusion step (1,994 → 924 → 718 → 708), 8 stapled ERα structures added back (716), cofactor names from UniProt, experimental metadata, stoichiometry, unusual structures. |
| `november_2026/` | Clustering benchmark (10 methods), classification, cofactor vs receptor, within-receptor splits (RORγ, PPARα, …), resolution check, pairwise landmark distances and descriptor ranking; report PDF and slides. |

Each folder has its own README with the scripts, results and run order.
